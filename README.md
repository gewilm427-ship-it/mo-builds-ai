# Personal Website

This folder is ready for GitHub Pages.

## Structure

- `index.html` — main personal website
- `padel/index.html` — PadelPilot website

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder so `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder.
6. Save.

Your site will then be available at a GitHub Pages URL.

The PadelPilot link on the main page points to `padel/`, so it will open as its own page.
